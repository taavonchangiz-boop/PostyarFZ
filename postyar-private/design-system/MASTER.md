# Postyar Design System v2 — Soft UI Evolution (Dark Mode)

## Design Direction
- **Style**: Soft UI Evolution — evolved neumorphism with improved contrast, modern aesthetics, subtle depth
- **Source**: UI/UX Pro Max Skill (ui-ux-pro-max-skill)
- **Variance**: 6/10 (Modern), **Motion**: 6/10 (Standard), **Density**: 7/10 (Standard)

## Key Design Principles
1. **No emojis as icons** — Use inline SVGs (Lucide-style)
2. **Soft depth** — Subtle shadows instead of hard borders
3. **Improved contrast** — Minimum 4.5:1 for all text
4. **Accessible focus states** — Visible outlines on keyboard nav
5. **Smooth transitions** — 120-300ms with proper easing
6. **Reduced motion** — Respect prefers-reduced-motion
7. **RTL-first** — All layout uses logical properties
